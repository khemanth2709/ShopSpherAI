# ShopSphere AI – Next 200 photo update

- Previous bundled generated photo assignments: 350.
- New individual WebP images in this update: 200.
- Total generated photo assignments: 550 of 750 products.
- Products retaining the original SVG fallback: 200.

**Image disclosure:** these are AI-generated illustrative product catalogue images, not Amazon listing downloads or manufacturer-verified SKU photographs. Some of the 150 catalogue-grid crops are category-level thumbnails rather than exact model photography. Use licensed supplier/manufacturer assets for exact SKU representation.

Each new image is a separate local file in `public/product-photos/generated/`. The product manifest, photo manifest, and TypeScript seed map were updated. Existing SQLite databases can apply the manifest using `npm run photos:apply-bundled`; the migration preserves merchant/supplier/ licensed photos.
